# Memory Lane

Кроссплатформенная игра на память на `React Native + Expo + TypeScript` с двумя режимами:

- уровни с прогрессом и локальным сохранением;
- бесконечный режим с плавным ростом сложности.

Основная механика реализована как "скользящее окно":

1. игрок видит несколько первых элементов последовательности;
2. элементы закрываются;
3. игра спрашивает, что находится под текущим закрытым элементом;
4. при правильном ответе этот шаг подтверждается, справа показывается следующий новый элемент;
5. новый элемент снова скрывается, и игра продолжает опрос по порядку.

## Запуск

```bash
npm install
npm run start
```
